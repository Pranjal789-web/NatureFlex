
# NatureFlex 🌿

A nature-themed walk-and-earn web application.

## Features
- Step-counting prototype
- Seed rewards and tree planting
- User registration and login
- Flask API and MySQL database
- Nature-inspired interface

## Technologies
- HTML, CSS, JavaScript
- Python Flask
- MySQL

## Local Setup
1. Install Python and MySQL.
2. Create the database using schema.sql.
3. Configure backend environment variables.
4. Install requirements:
   pip install -r requirements.txt
5. Run the Flask application.

## Security
Never commit .env files, passwords, or real user data.
